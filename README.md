I programmed this website for my Client-Side Scripting class, in which I was tasked with creating a responsive survey website using HTML, CSS, and JavaScript. I was given specific instructions for JavaScript in this assignment, as noted in the comments of my code. I developed this website by first creating a structured HTML foundation. To ensure form validation with specific user input, user feedback, and submission handling, I implemented DOM manipulation, regular expression validation, and event listeners for user feedback. Additionally, I programmed the website to have pop-up boxes that display user answers and a badge. I included a badge system so users could get different badges depending on their answers. I created and incorporated two badges using Photoshop and implemented them in my code. I styled the site with CSS and JavaScript to achieve a specific 90’s design and aesthetic.
